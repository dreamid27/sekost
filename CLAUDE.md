# Sekost

Android app (Kotlin, Jetpack Compose, Hilt, Room) for managing kost and rental houses. See
[README.md](README.md) for the stack, folder structure, design system, and code conventions.

- Build, test, format: see "Getting started" in [README.md](README.md). Run `./gradlew spotlessCheck testDebugUnitTest` before you finish.
- Deployment (Firebase App Distribution, signing, testers): [DEPLOYMENT.md](DEPLOYMENT.md)
- Never commit `keystore/` or `keystore.properties`.
